# Навигация

| Действие | Горячая клавиша | Когда использовать |
|---|---:|---|
| 🔎 **Search Everywhere** | `Shift` → `Shift` | Найти файл, класс, действие или настройку |
| 📄 **Найти файл** | `Ctrl + Shift + N` | Быстро открыть `product.php`, `category.php`, `cart.tpl` |
| 🧩 **Найти класс** | `Ctrl + N` | Перейти к нужному PHP-классу |
| 🎯 **Перейти к объявлению** | `Ctrl + B` / `Ctrl + Click` | Найти, где определён метод, класс или переменная |
| ⬅️ **Назад** | `Ctrl + Alt + Left` | Вернуться туда, откуда перешёл |
| ➡️ **Вперёд** | `Ctrl + Alt + Right` | Вернуться вперёд после перехода назад |
| 🗂️ **Показать Project** | `Alt + 1` | Открыть или скрыть левую панель проекта |
| 🧭 **Найти текущий файл в Project** | `Alt + F1` → `Project View` | Развернуть дерево и выделить открытый файл |
| 🔁 **Переключение файлов** | `Ctrl + Tab` | Быстро прыгать между открытыми файлами |
| 🕘 **Недавние файлы** | `Ctrl + E` | Вернуться к недавно открытым файлам |
| ✏️ **Недавние изменения** | `Ctrl + Shift + E` | Найти недавно редактировавшиеся участки |

> [!tip]
> Если потерялся в проекте, чаще всего достаточно трёх команд:  
> **`Shift` → `Shift`**, **`Ctrl + B`**, **`Alt + F7`**.

# Поиск и анализ

| Действие | Горячая клавиша | Зачем |
|---|---:|---|
| 🔍 **Поиск по проекту** | `Ctrl + Shift + F` | Найти строку, SQL-фрагмент, маршрут или имя функции |
| ♻️ **Замена по проекту** | `Ctrl + Shift + R` | Массовая замена по проекту |
| 🔗 **Find Usages** | `Alt + F7` | Увидеть все места использования элемента |
| 🌳 **Call Hierarchy** | `Ctrl + Alt + H` | Понять, кто вызывает метод и как строится цепочка вызовов |
| 🧠 **Расширить выделение** | `Ctrl + W` | Выделять выражение → блок → метод → более крупную конструкцию |

> [!warning]
> **`Ctrl + Shift + R`** на старом проекте используй очень осторожно.  
> Перед массовой заменой лучше проверить Git diff или сделать резервную копию.

# Работа с кодом

| Действие | Горячая клавиша | Совет |
|---|---:|---|
| ✨ **Форматировать код** | `Ctrl + Alt + L` | Лучше применять к выделенному фрагменту |
| 🪄 **Быстрые исправления** | `Alt + Enter` | Посмотреть предложения PhpStorm |
| 💡 **Параметры метода** | `Ctrl + P` | Быстро посмотреть аргументы функции |
| 📚 **Документация** | `Ctrl + Q` | Показать PHPDoc и описание элемента |

> [!note]
> На старом OpenCart не стоит форматировать целый файл без необходимости:  
> иначе в Git можно получить огромный diff из-за одних только отступов и переносов строк.

# Любимая связка для OpenCart

Когда нужно понять:

- где объявлена функция;
- кто её вызывает;
- какие файлы от неё зависят;
- как быстро вернуться обратно.

```text
Ctrl + Shift + F
        ↓
найти getProducts(
        ↓
Ctrl + B
        ↓
перейти к реализации
        ↓
Alt + F7
        ↓
посмотреть все использования
        ↓
Ctrl + Alt + H
        ↓
посмотреть дерево вызовов
        ↓
Ctrl + Alt + Left
        ↓
вернуться назад
```

## Пример

Допустим, в контроллере встречается:

```php
$this->model_catalog_product->getProducts($data);
```

Тогда:

1. Поставить курсор на `getProducts`.
2. Нажать `Ctrl + B`.
3. Изучить реализацию метода.
4. Нажать `Alt + F7`.
5. Посмотреть все места использования.
6. Нажать `Ctrl + Alt + H`.
7. Изучить дерево вызовов.
8. Вернуться назад через `Ctrl + Alt + Left`.

> [!success]
> Такая последовательность позволяет быстро восстановить логику даже в незнакомом старом проекте.

# Полезная настройка

В панели **Project** открой:

**⋮ / ⚙ → Always Select Opened File**

В некоторых версиях PhpStorm эта настройка называется:

**Autoscroll from Source**

После этого PhpStorm будет автоматически раскрывать дерево проекта и выделять файл, который сейчас открыт в редакторе.

> [!tip]
> Для работы с большим проектом эту настройку почти всегда стоит держать включённой.
