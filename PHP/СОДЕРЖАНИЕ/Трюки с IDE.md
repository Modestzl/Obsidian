#PHPSTORM

>[!note]- Вставка одинакового символа перед всеми строками блока.
> - **Нажмите `Alt + Shift + Insert`** (Windows/Linux)
> - **Нажмите `Alt + J`** (или `Shift + Alt + J` для снятия выделения) — поставит курсоры перед каждой строкой.
> - или **Без колоночного режима (проще):** Зажмите `Alt` и кликайте в начало каждой строки — добавится курсор 
> - 

```function sum($a, $b,...$nums)  
> {  
>    $result = $a*$b;  
>    foreach ($nums as $num) {  
>        $result += $num;  
>    }  
>    return $result;  
> }  
>  
> echo 'Результат суммирования '. sum(1,2,3,4,5);  
>
```
