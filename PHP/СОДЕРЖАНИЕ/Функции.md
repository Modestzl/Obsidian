Функция  PHP может принимать неограниченное количество аргументов.  Или список аргументов переменной длины.

```
<php error_reporting(-1);
	function sum(...$nums)  
{  
    $result = 0;  
    foreach ($nums as $num) {  
        $result += $num;  
    }  
    return $result;  
}  
  
echo 'Результат суммирования '. sum(1,2,3,4,5);

```
