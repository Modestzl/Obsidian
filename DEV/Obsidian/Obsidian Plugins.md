# О Mermaid

**[[Mermaid]] позволяет создавать диаграммы и визуализации с помощью текста и кода.**

Это инструмент для создания диаграмм и графиков на основе JavaScript, который преобразует текстовые определения в стиле Markdown для динамического создания и изменения диаграмм.

**Плагины.** Для автоматизации некоторых задач (например, формирования списка литературы) можно использовать плагины. Например, плагин **Better BibTeX** позволяет связать Zotero с Obsidian, а плагин **Pandoc Reference List** помогает вставлять референсы и генерировать список литературы.

Если вам нужно действительно автоматическое оглавление, которое собирается из заголовков вашей заметки, используйте плагин **Automatic Table of Contents**. В его настройках можно выбрать стиль `nestedOrderedList`, и он сам создаст идеально вложенную структуру на основе ваших заголовков H1, H2 и H3[](https://github.com/johansatge/obsidian-automatic-table-of-contents/issues/41).

Также для организации целой базы знаний с папками и связями, как в книге, обратите внимание на плагин **Breadcrumbs** — он строит навигационные цепочки[](https://habr.com/en/articles/806339/), или **VirtFolder**, который позволяет создать иерархию заметок, не меняя их реальное расположение на диске[](https://habr.com/en/articles/1000254/).

**Совет:** Начните с 3 заметок (например, «Переменные», «Функции», «Циклы»). Когда их станет 20+, установите плагин **Graph Analysis** — увидите слабые места в знании языка.

Добавьте в начало каждой заметки метаданные. Это позволит использовать **Dataview** (самый мощный плагин).
