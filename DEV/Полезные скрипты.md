> [!success]+ Генерация тестовых данных для нагрузки на сервер.
> **Пример:** Создать 10 000 заказов для нагрузки на БД.
> ```
> from faker import Faker
>import json
>fake = Faker()
>data = []
>for _ in range(10000):
  >  data.append({
 >       "order_id": fake.uuid4(),
 >       "price": fake.random_int(100, 10000),
 >       "city": fake.city(),
 >       "items": [fake.word() for _ in range(fake.random_int(1, 5))]
 >   })
>with open("test_data.json", "w") as f:
 >   json.dump(data, f)
> ```
