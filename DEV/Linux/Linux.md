fc 121 122 - открывает текстовый редактор с текстом команд, потом сохранить выполняются автоматом при выходе

>[!tip]- Сравнить два файла ```comm```
>```
>	// **Важное условие:** оба файла должны быть **предварительно отсортированы**. Если нет — сначала сортируем:
>	comm -12 <(sort 1.txt) <(sort 2.txt)
>	
>// # показать только тех, у кого shell присутствует в /etc/shells (список разрешённых оболочек)
>comm -12 <(grep -v '^#' /etc/shells | sort) <(awk -F: '{print $NF}' /etc/passwd | sort) | while read sh; do grep ":$sh$" /etc/passwd; done
># Просто сокращенный Вариант. Но может подхватить лишнего в вывод.
>grep -vE '/nologin$|/false$' /etc/passwd
>```
