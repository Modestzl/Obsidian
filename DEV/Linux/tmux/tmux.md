// Старт новой сессии. Создать сессию с именем по умолчанию обычно (0).
- ```tmux```
// Отключение от сессии. По умолчанию префикс — Ctrl+b. 
// То есть зажимаешь Ctrl, нажимаешь b, отпускаешь, потом жмёшь d.
// Ты вернёшься в обычный терминал, а сессия продолжит работать в фоне.

// Подключение к существующей сессии (attach)
 - ``tmux attach       # подключиться к последней активной
- ``tmux attach -t mysession   # подключиться к конкретной

// Список сессий
- ``tmux ls
// Убить сессию.
- ``tmux kill-session -t mysession
//

|                |  Окна (windows)                         |     |
| -------------- | --------------------------------------- | --- |
| **Команда**    | **Действие**                            |     |
| Prefix + c     | Создать новое окно                      |     |
| Prefix + ,     | Переименовать текущее окно              |     |
| Prefix + w     | Интерактивный список окон               |     |
| Prefix + &     | Закрыть текущее окно (с подтверждением) |     |
| Prefix + n     | Перейти к следующему окну (next)        |     |
| Prefix + p     | Перейти к предыдущему окну (previous)   |     |
| Prefix + [0-9] | Перейти к окну по номеру                |     |


|            | Создание панелей                         |
| ---------- | ---------------------------------------- |
| Prefix + % | Разделить окно по вертикали (лево/право) |
| Prefix + " | Разделить окно по горизонтали (верх/низ) |



|                  | Навигация по панелям                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| Prefix + стрелки | Переход на соседнюю панель                                                |
| Prefix + o       | Переход к следующей панели по кругу                                       |
| Prefix + ;       | Вернуться к предыдущей активной панели                                    |
| Prefix + q       | Показать номера панелей (кратковременно), затем нажать цифру для перехода |
