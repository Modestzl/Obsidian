>[! tip]- Очистка оперативной памяти
>```cach
>sync; echo 1 > /proc/sys/vm/drop_caches
>или более безопасная
>sync && echo 3 > /proc/sys/vm/drop_caches
> - `3` = очистка page cache + dentries + inodes (более полная очистка)
> - - `&&` вместо `;` — прекратит выполнение, если sync не удастся
 >```

>[!tip]- правильно копируем sudoers
>```
>#- Создайте резервную копию файла конфигурации 
>sudo /etc/sudoers: `sudo cp --archive /etc/sudoers /etc/sudoers-COPY-$(date +"%Y%m%d%H%M%S")`
>```
>
>  `--archive` (или короткая форма `-a`)
>Это ключ **режима архивации**. Он включает в себя сразу несколько опций (`-dR --preserve=all`).
>
>
>**Почему это критично:** Если вы сделаете копию без `--archive` (обычным `cp`), новая копия создастся с вашими текущими правами пользователя и группы. Если потом вы случайно попытаетесь использовать эту копию как основной файл, `sudo` перестанет работать с ошибкой _"sudoers file is world writable"_.
>
