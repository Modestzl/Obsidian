## Правила достоверности

**Код** — вывод подтверждён прочитанным кодом этой копии. Это не доказательство такого же поведения рабочего сервера.

**Гипотеза** — косвенные признаки; нужна дополнительная проверка.

**Внешние данные** — невозможно установить без выбранных настроек БД, конфигурации сервера или проверки работающего сайта.

Наличие файлов расширения не означает, что оно включено. Отсутствие прямой ссылки не доказывает неиспользование: OpenCart загружает контроллеры, модели и модули по строковым маршрутам и настройкам. Кеши и папки с похожими названиями не считаются автоматически ни актуальными, ни ненужными.
