# Ссылка в заголовке «Новости» — применено локально

05.10.2026. Пользователь поручил сделать заголовок ссылкой на `https://amital.ru/information/news.html`.

Целевой файл: [catalog/view/theme/ami6/template/module/news.tpl:4](E:/GPT/amital/amital_ru/catalog/view/theme/ami6/template/module/news.tpl:4).

Разметка `news-region`, карточек и нижней кнопки соответствует предоставленному скриншоту. В `ControllerModuleNews::index()` файл выбирается через `config_template`; активность темы на сервере по БД не проверена. В просмотренных `vqmod/xml/*.xml` нет правил для этого шаблона; кеш с именем news не найден. CSS темы уже поддерживает ссылки внутри заголовков, что применяется и в других блоках. Изменение состоит только из HTML и не требует новых возможностей PHP.

Было:
```html
<h2>Новости</h2>
```

Стало:
```html
<h2><a href="https://amital.ru/information/news.html">Новости</a></h2>
```

Переход — в той же вкладке, в том числе с клавиатуры. Адрес абсолютный по запросу пользователя: на тестовой копии также ведёт на amital.ru. Нижняя кнопка и карточки не меняются.

[Готовый патч](E:/GPT/amital/docs/news-heading-link.patch), пути в нём отсчитываются от `E:\GPT\amital\amital_ru`.

## Применение и проверка

1. Локальный файл уже изменён. Перед установкой на сервер сверить его текущую версию и сохранить серверный исходник отдельно: локальная копия может отличаться.
2. Открыть главную и нажать «Новости» — должен открыться указанный URL. Проверить также Tab/Enter и мобильный вид.
3. Убедиться, что карточки и кнопка «Смотреть все новости» работают как прежде. Кеш vQmod без необходимости не очищать.
4. Для локального отката вернуть прежнюю строку `<h2>Новости</h2>` либо восстановить резервный файл по исходному пути, если после него не было других изменений. Для серверного отката использовать сохранённую серверную версию.
